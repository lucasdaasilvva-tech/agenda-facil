Agenda Fácil

Sistema de Agendamento de Serviços

Sobre o projeto

O Agenda Fácil é um sistema desenvolvido em Python com o objetivo de facilitar o cadastro de clientes e o gerenciamento de agendamentos de serviços.

Objetivo

Desenvolver uma aplicação simples e prática que permita organizar os atendimentos, consultar clientes e controlar os horários agendados.

Funcionalidades

* Cadastrar clientes.
* Pesquisar clientes cadastrados.
* Listar clientes.
* Realizar agendamentos.
* Listar agendamentos.
* Verificar conflitos de horários.
* Encerrar o sistema.

Tecnologia utilizada

* Python 

Como executar

1. Instale o Python 3.
2. Baixe o arquivo agenda_facil_py3.py.
3. Abra o arquivo em um editor Python, como o Thonny.
4. Execute o programa.
